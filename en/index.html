    About This Game

    "3-Second Decision RPG" is a free browser game in which you keep choosing options within 3 seconds as you head for the Demon King. Each choice changes your stats, equipment, allies and money, and the ending changes depending on that state. Running out of time is also an ending. Collect all 46 endings and complete the codex. One run takes only a few minutes.
